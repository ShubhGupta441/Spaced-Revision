# Spaced Revision (Nexus)

An intelligent, active-recall study companion and spaced repetition tracker built with React 19, Vite, Tailwind CSS v4, and Framer Motion.

## Features

- 🧠 **Spaced Repetition System (SRS)**: Built-in scientific revision intervals (Day 1, 3, 5, 15, and 30) ensuring long-term memory retention.
- 🎓 **AI Learning Companion & Tutor**: Interactive curriculum-tailored tutor for school (K-12) and university/engineering topics.
- ✨ **Auto Topic Generator**: Generate structured syllabi and topic hierarchies (e.g., DSA, React, Python) with one-click integration into your study plan.
- 📅 **Interactive Calendar**: Visual monthly schedule showing upcoming, pending, and overdue revision sessions.
- 📊 **Analytics & Reports**: Visual progress tracking, study streak calculator, retention scores, and achievement milestones.
- ⏱️ **Focus Stopwatch**: Built-in distraction-free focus timer to track deep study sessions.
- 🎲 **Random Review**: "Roll the Dice" rapid-recall challenge pulling from missed or mastered topics.
- 🌗 **Dark Mode & Glassmorphism UI**: Beautiful, modern responsive UI with fluid animations.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Charts**: Recharts

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ShubhGupta441/Spaced-Revision.git
   cd Spaced-Revision
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
